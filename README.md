# Mathematical formalization with Lean 4

This repository contains the materials for the course **"Mathematical formalization with Lean 4"**, taught at [**ICMAT**](https://www.icmat.es/) as part of the school [AI and Mathematics Days](https://www.icmat.es/congresos/2026/AIMD/) (September 14-16, 2026).

## Installation Instructions
Lean 4 installation instructions can be found [here](https://lean-lang.org/install/).

After installing Lean 4, clone the repository using
```
git clone https://github.com/mariainesdff/icmat_26
```

Then navigate to the `icmat_26` directory and run `lake exe cache get!` to get a compiled version of the Mathlib cache.

Type `code .` to open the folder in `VS Code`.

If you have trouble with the Lean installation, you can open the course files in the online editor [https://live.lean-lang.org/](https://live.lean-lang.org/)
